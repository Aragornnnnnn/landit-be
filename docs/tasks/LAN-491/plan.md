# LAN-491 한국어 퀴즈 복수 정답.

## 반영 범위.

- PR #191은 `feat/LAN-461`의 `86acb036`을 base로 한다.
- 표현 3,000개의 1·2번 예문 6,000개에 원본 포함 정답 배열 23,392개를 저장한다. 어색하지 않고 의미가 같은 어순을 검토했으며 정답 개수 상한은 없다. 복수 정답 예문은 5,876개, 단일 정답은 124개이다.
- 대상 중 오답이 4개인 33개 예문만 오답 하나를 제거한다. 나머지 보기, 3·4번 예문, 영어·질문·번역·이미지·대표 문장은 유지한다.
- yes/no 응답·번역 원문 오류와 앱의 채점 연동은 별도 범위이다.

## 마이그레이션.

`src/main/resources/db/postgresql/V109__add_korean_quiz_accepted_answers.sql`이 적용 데이터의 기준이다. 기존 JSONB에 `sentenceTranslateAcceptedAnswers`를 추가하며 테이블 컬럼 변경은 없다.

Flyway 트랜잭션 안에서 쓰기 잠금을 잡고 대상 ID·소스·예문 수·문장·질문·정답·보기의 정확한 일치를 확인한다. 기존 복수 정답 키가 있거나 원문이 다르면 표현 ID와 예문 번호를 포함한 오류로 중단한다. 적용 후 전체 payload에서 승인된 두 필드 외의 값이 유지되는지도 확인하며, 실패하면 모두 롤백한다. 대상 표현의 `updated_at`은 함께 갱신한다.

## API와 앱 연동.

`GET /api/v1/expressions/{expressionId}/practice`의 `data.writingSentence[]`에 다음 계약을 적용한다.

| 필드 | 계약 |
| --- | --- |
| `quizLanguage` | 기존대로 `EN`·`KR` 문제를 하나씩 배정한다. |
| `writingSentenceWords` | 기존 정답 `string[]`를 유지한다. |
| `writingSentenceWordChoices` | 기존 보기 `string[]`를 유지하며 33개 보기 수정도 반영한다. |
| `writingSentenceAcceptedAnswers` | 허용 정답 `string[][]`이다. 첫 배열은 기존 정답이며, 한국어는 모든 검토 정답을, 영어는 정답 하나를 담는다. |

저장 필드가 없거나 올바른 추가 정답이 없어도 기존 정답 하나로 응답한다. 추가 배열은 원본과 토큰별 개수가 같아야 하며 중복만 제거한다. 런타임에 새 어순을 생성하지 않는다.

앱은 입력 토큰의 순서·값·개수가 허용 배열 중 하나와 모두 일치하면 정답으로 처리해야 한다. 구버전 BE 응답에는 새 필드가 없으므로 앱에서 `[writingSentenceWords]`로 대체할 수 있다. BE의 학습 완료 API는 입력 토큰을 받거나 채점하지 않는다.
