# LAN-491 한국어 퀴즈 데이터 검토 샘플.

복수 정답 검토 대상 6,000개 중 문장 유형을 확인하기 위한 30개 샘플이다. 추가 어순을 제안한 20개와 기존 정답 하나를 유지한 10개를 함께 검토한다. 통계 표본이나 전수 검토 완료본이 아니다.

추가 정답은 원래 단어 조각과 중복 횟수를 그대로 사용한다. 아래 정답의 `/`는 단어 조각의 경계이며 실제 단어가 아니다. 원문 문장부호는 한국어 원문을 참고한다. JSONL에는 정확한 배열이 들어 있다.

## 복수 정답 샘플.

### 1. 표현 1944 · 예문 1 · 사용자 제보: 관형절 내부 어순.

질문: Why do you run every morning?

넌 왜 매일 아침 달려?

영어 예문: What I like about running is the quiet.

한국어 원문: 달리기에서 내가 좋아하는 점은 조용하다는 거야.

- 기존 정답: `달리기에서 / 내가 / 좋아하는 / 점은 / 조용하다는 / 거야`.
- 추가 정답: `내가 / 달리기에서 / 좋아하는 / 점은 / 조용하다는 / 거야`.
- 판단 근거: 관형절 안에서 주어와 활동 범위를 바꾸어도 좋아하는 대상과 이유가 같다.
