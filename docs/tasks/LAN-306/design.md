# LAN-306 OpenAPI 스키마 충돌 수정 설계

## 목표와 설계

- 시나리오와 프리톡 DTO의 중첩 record 단순 이름 충돌을 제거한다.
- 프리톡 중첩 DTO에 고유한 OpenAPI 컴포넌트 이름을 지정한다.
- 런타임 JSON 필드와 Java 타입 구조는 변경하지 않는다.

## 검증

- `/v3/api-docs`에서 프리톡 시작·제출 응답이 프리톡 전용 컴포넌트를 참조하는지 확인한다.
- 프리톡과 시나리오 컴포넌트의 필드 집합이 서로 오염되지 않았는지 확인한다.
