# LAN-462 어드민 푸시 캠페인

## 요구사항

- 전체 사용자 또는 선택 사용자에게 제목·내용·딥 링크로 푸시 발송.
- 대상 선택: 개별 클릭, ID 붙여넣기, 읽기 전용 SQL 조회를 조합하고 제외 ID 지원. 캠페인 1,000명 제한 제거.
- 사용자 목록: 활성 여부·알림 동의 필터와 페이지 번호 제공.
- 관리자 본인 테스트, 예상 대상·발송 결과 조회, 한국 시간 일회성 예약·취소 지원.
- 예약 SQL은 발송 시 재조회하여 설문 미응답자 등 최신 조건 적용.
- SQS·Expo 100건 배치와 캠페인별 중복 방지 유지. 20시 학습 알림 상태에 영향 없음.
- 관리자 권한·입력 검증·감사 로그 적용. 생성 후 내용과 대상 조건 고정.
