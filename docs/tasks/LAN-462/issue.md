# LAN-462 어드민 전체 푸시 발송

## 요구사항

- 관리자가 제목, 내용, 딥 링크로 캠페인을 생성하고 본인 테스트 후 전체 발송할 수 있다.
- 전체 발송 대상은 활성 사용자의 활성 Expo Push Token이며 Token당 한 건을 발송한다.
- 전체 발송은 SQS에서 최대 100건씩 처리한다.
- 캠페인 ID, 사용자 ID, Token ID로 중복 발송을 막는다.
- 캠페인 원문은 생성 후 수정할 수 없다.
- 예상 대상 수와 대상·성공·실패·제외 수를 조회할 수 있다.
- 공지는 예약 학습 알림과 별도 키를 사용하며 `user_notification_state`를 변경하지 않는다.
- 내부 `/...` 경로와 유효한 외부 `https://...` URL만 허용한다.
- 생성·테스트·전체 발송을 관리자 감사 로그에 기록한다.

## 완료 기준

- [x] 관리자 본인 테스트 및 전체 발송 API.
- [x] SQS 페이지 처리와 `push_delivery` 기반 중복 방지.
- [x] 캠페인 상태와 Token 기준 결과 집계.
