# LAN-605 스몰톡 예고 질문을 활용한 지난 대화 이어가기

## 확정된 흐름

- 스몰톡 메인 조회에 캐릭터별 사용 가능한 질문 ID와 문구를 제공한다. FE는 이번 작업 범위에서 제외한다.
- 이어가기 선택은 기존 세션 시작 API의 `AI_FIRST`와 `followUpId`를 사용한다. `topicId`와는 함께 보내지 않는다. 일반 주제 시작·사용자 선발화 계약은 유지한다.
- 질문은 서버가 ID로 다시 조회한다. 원문은 클라이언트가 시작 요청에 보내지 않는다.
- AI는 질문을 학습 언어로 자연스럽게 물으며, 실제 첫 AI 메시지 저장과 질문 사용 확정을 같은 트랜잭션에서 처리한다.

## 구현 순서와 발견 사항

1. BE: 질문 조회·선점·확정 상태, 메인 응답, 시작 요청, AI 요청/응답, OpenAPI와 통합 테스트.
2. AI: 주제가 없는 명시적 후속 질문 오프닝 허용 및 계약 테스트.
3. FE 연동에 필요한 응답과 요청 계약을 문서화한다. 화면과 FE 코드는 변경하지 않는다.

- 운영 BE는 예고 질문을 저장·조회하지만 다음 AI 요청에 전달하지 않는다. AI에는 `pendingFollowUp` 처리와 `followUpAsked` 응답이 이미 있다.
- AI의 현재 오프닝 검증은 주제 ID와 설명을 필수로 하므로 이어가기 오프닝에서만 예외를 둔다.
- 기존 `free_talk_follow_up`에 사용/선점 정보가 없으므로 Flyway 변경이 필요하다. 최초 V139는 develop의 콘텐츠 교정과 충돌하여 사용자 지정 V142로 변경했다. 적용 전 선행 버전 반영 여부를 다시 확인한다.
- 질문 선점에는 만료 시간이 필요하다. 선점 만료 후 다른 시작이 질문을 가져가면 이전 오프닝 저장은 실패해야 한다. AI 생성 실패는 세션 정리와 함께 선점을 해제한다.

## 검증 기록

- BE `./gradlew spotlessApply check --offline` 통과. 메인 질문 조회, 이어가기 첫 발화·사용 확정, 재사용 거부, AI 호출 실패 시 선점 해제, 원격 AI 계약을 검증했다.
- AI `/Users/sangmin8817/Soma/landit-ai/.venv/bin/python -m unittest discover -s tests` 통과: 836개 실행, 7개 건너뜀. 샌드박스 실행은 토크나이저 다운로드와 로컬 테스트 서버 바인딩 제한으로 실패하여 허용된 환경에서 재실행했다.
- FE 테스트와 화면 검증은 이번 범위에서 제외한다. BE·AI의 로컬 검증은 배포나 실제 사용자 경험을 증명하지 않는다.

## 리뷰 수정 및 재검증 (2026-10-03)

- Flyway 파일을 V142로 변경해 develop의 V139와 버전 충돌을 해소했다.
- AI는 일반 의문사만 겹치거나 인사·평서문에서만 주제를 언급한 응답을 질문 사용으로 확정하지 않는다. 질문문에서 고유 단서를 확인하며, 근거가 없으면 기존 재생성을 시도한다. 단어 기반 검증이므로 의미 일치를 완전히 보장하지는 않는다.
- 로컬 AI 대체 구현도 선택한 질문과 ID, 사용 확인을 반환하도록 수정했다. 번역 모델 없이 저장 질문을 그대로 반환하는 로컬 구현이며, 실제 구현을 사용하는 세션 통합 테스트로 사용 확정과 재사용 거부를 확인했다.
- BE `./gradlew spotlessApply check --offline` 통과. AI 전체 테스트 839개 실행, 실패 0개, 7개 건너뜀. AI 사용 확인이 false인 원격 응답의 BE 거부도 검증했다.
