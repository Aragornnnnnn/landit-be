# LAN-602 사용자 수준 100점 평가

## 범위와 기준

- 사용자 승인 범위: AI 영역 평가와 종합 점수는 1~100, 학습 레벨과 콘텐츠 난이도 연결은 1~5 유지.
- 구현 기준: 영역별 정수 1~100, 영역/종합 계산은 소수 둘째 자리 HALF_UP. 기존 영역 가중치 30/20/20/15/15와 질문 요구 난이도 가중치를 유지한다.
- 학습 레벨은 (0,20], (20,40], (40,60], (60,80], (80,100]이며 유효 점수 최솟값은 1이다. 사용자가 20점 구간을 승인했다.
- 최초 충분한 평가는 레벨을 확정한다. 이후 하락 없음, 2회 연속 승급 신호일 때 1단계 상승을 유지한다. 승급 신호는 현재 레벨의 상한+4점(24/44/64/84) 이상이다. 기존 다음 경계보다 0.2 높은 완충 폭을 20점 구간의 4점으로 적용한다.
- 질문 그룹별 종합 상한은 LEVEL_1=40, LEVEL_2_TO_3=80, LEVEL_4_TO_5/DIAGNOSTIC=100. 영역 점수 자체는 제한하지 않는다.
- 각 영역 관찰 수 2회 및 confidence 0.75 기준, 미관찰 null, fallback, 수동 수준 변경/최신 세션 보호는 유지한다.

## 계약과 과거 데이터

- AI 도메인 출력 `level`을 `score`로 변경한다. 구버전 1~5 값을 100점으로 오인하지 않으며 계약 불일치는 기존 fallback으로 처리한다.
- BE 저장 버전 `text-score-v2.0`, API에 `scoreMax`(신규 100/과거 5)를 추가한다. `assessedLevel`, `currentLevel`, `previousLevel`, `displayLevel`은 여전히 1~5다.
- V134에서 점수 6개 컬럼만 NUMERIC(5,2)로 확장한다. 과거 수치·버전·JSON·확정 레벨·승급 신호는 수정하지 않는다.
- 열린 PR의 V126~V133을 확인해 V134를 배정했다. 병합/배포 전에 하위 마이그레이션 포함 여부와 버전 충돌을 다시 확인한다.
- BE #228의 총평 userLevelAssessment 노출은 동일 응답 record를 사용한다. 해당 PR의 FE 100점 환산 정책은 신규 scoreMax=100에서 적용하면 안 된다. AI #123/#124는 같은 프롬프트 파일을 수정하므로 통합 시 양쪽 변경을 보존해야 한다.
- DB 확장 및 scoreMax를 인식하는 앱과 AI/BE를 함께 준비한 뒤 평가 요청을 잠시 중지하고 함께 전환한다. 버전이 어긋난 동안 fallback이 생길 수 있다. 구버전 클라이언트 표시까지 검증하지 않은 상태로 단독 배포하지 않는다.
