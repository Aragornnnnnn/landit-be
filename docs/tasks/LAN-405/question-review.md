# LAN-405 시나리오 질문 검수 기준

## 검수 대상

- 기준 데이터: 2026-08-31 develop DB 활성 시나리오 40개.
- 신규 질문: `LEVEL_1` 120개, `LEVEL_2_TO_3` 120개.
- 비교 기준: `LEVEL_4_TO_5` 120개. 기존 DB 원문이므로 수정하지 않는다.
- 시나리오의 브리핑, 대화 목표, 시작 화자, AI 역할도 수정하지 않는다.

## 판정 규칙

아래 1~8은 필수 규칙이다. 하나라도 위반하면 해당 레벨을 `REVISE`로 판정한다.

1. **공통 목표 충족.** 사용자 시작 안내와 고정 AI 발화 3개를 합쳐 기존 `conversation_goal`의 관찰 가능한 결과를 빠짐없이 충족한다. 레벨을 낮추더라도 목표 결과 자체를 빼거나 다른 결과로 바꾸지 않는다.
2. **답변 출처.** 각 답은 현재 AI 발화의 정보, 사용자의 쉬운 실제 취향·경험, USER First의 시작 안내 중 하나에서 나온다. 제공되지 않은 일정, 예산, 물건, 과거를 억지로 만들게 하지 않는다.
3. **분기 독립성.** 사용자가 허용된 범위에서 어떤 답을 해도 다음 고정 발화가 성립한다. 앞 답을 특정 선택으로 단정하지 않는다.
4. **목표 전진성.** 같은 결정을 다시 묻지 않고 매 턴 목표의 다음 결과로 이동한다. 질문 수를 채우기 위한 주변 질문은 넣지 않는다.
5. **역할 현실성.** AI 역할이 실제로 제공할 수 있는 정보와 조치만 말한다. 필요한 가격, 시간, 선택 조건은 선택을 요구하는 현재 발화에서 제공한다.
6. **레벨 구분.** `LEVEL_1`은 초등학생도 이해할 짧고 직접적인 단어와 한 번에 답하기 쉬운 과업을 쓴다. `LEVEL_2_TO_3`은 같은 목표를 유지하면서 비교 정보나 간단한 설명을 한 단계 더 요구한다. 불필요하게 심오한 이유나 추상적 판단은 요구하지 않는다.
7. **언어 계약.** 영어와 한국어의 정보, 수치, 선택지, 격식이 일치하고 두 언어 모두 실제 역할 대화처럼 자연스럽다. 신규 영어 발화는 25단어 이하로 쓴다.
8. **구조 계약.** 각 레벨은 시나리오당 AI 발화 3개와 번역 3개를 갖는다. AI First 신규 첫 발화는 `GOOD` 속마음을 갖고, USER First는 기존 시작 안내를 사용한다.

다음 항목은 품질 권장 규칙이다.

- 세 발화 중 하나는 사용자가 한 문장으로 설명, 요청, 조정, 협상할 수 있게 한다.
- 세 발화를 모두 같은 양자택일 형식으로 만들지 않는다. 다만 주문, 시간, 좌석처럼 짧은 선택이 자연스러운 거래 흐름은 예외로 둘 수 있다.
- 한 발화에는 핵심 과업 하나를 둔다. 공통 목표를 세 턴에 담기 위해 서로 직접 연결된 두 정보를 묻는 경우에만 예외로 둔다.
- 이유는 과제 형식 선택이나 가격 협상처럼 공통 목표에 이유가 명시된 경우에만 요구한다.
- `Which` 같은 문형의 반복 수치보다 상황에 맞는 자연스러움을 우선한다.
