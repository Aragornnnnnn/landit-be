## 승인된 범위

- 운영 3,000개와 `origin/develop` V127 추가 1,000개의 추가 예문 1·2번, 총 8,000문장이다.
- 첨부 SQL 신규 1,672개, 대표 문장, 추가 예문 3·4번은 제외한다.
- `sentenceWords`, `sentenceWordChoices`만 교정한다. 영어 원문, 질문, 번역, 한국어 정답, 이미지와 판정 코드는 유지한다.
- 다른 정답이 되는 보기는 교체하고 분리 가능한 구동사는 인접 칩을 묶는다. 묶은 만큼 전체 선택지 수가 줄어도 기존 오답 칩 수를 유지한다.
- 영어 칩만으로 해결 여부를 확정하지 못한 문장은 별도로 남긴다. 자동 탐색의 통과를 문맥상 단일 정답의 증명으로 간주하지 않는다.

- V139는 대상 ID/예문 번호, 출처, EN/KR 언어, 예문 수, 영문/국문 질문, 예문/번역, 기존 칩 배열과 순서를 확인한다. 값이 달라지면 전체 적용을 거부한다.

- PostgreSQL 회귀 테스트는 4,000개 실제 스냅샷과 범위 밖 4001/4329 표현을 적재한다. 정상 적용, 재실행 건너뛰기, 원본 변경 14종, 사후 변조 6종의 전체 롤백을 검증한다.

### 직접 검수 진행 기록.

- 현재 에이전트가 8,000문장의 영어 정답과 오답 보기를 전부 한 차례 읽었다. 보조 에이전트는 사용하지 않았다.

- 새 대체 답 832개가 기존 보기로는 조립 가능하고 교정 보기로는 불가능함을 확인했다. 동의어로 짧아지는 답, 단복수, 대명사, 조동사, 시간 표현 이동을 포함한다. 앞서 확인한 47개도 계속 통과한다.
