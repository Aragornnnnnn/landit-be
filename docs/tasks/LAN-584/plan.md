### 적용과 검증.

- V139는 대상 ID/예문 번호, 출처, EN/KR 언어, 예문 수, 영문/국문 질문, 예문/번역, 기존 칩 배열과 순서를 확인한다. 값이 달라지면 전체 적용을 거부한다.
- 같은 트랜잭션에서 두 영어 필드만 갱신한다. `updated_at`을 포함한 모든 다른 컬럼 및 예문 3·4번을 그대로 유지하고 전체 행을 사후 대조한다.
- PostgreSQL 회귀 테스트는 4,000개 실제 스냅샷과 범위 밖 4001/4329 표현을 적재한다. 정상 적용, 재실행 건너뛰기, 원본 변경 14종, 사후 변조 6종의 전체 롤백을 검증한다.

- FE 임시 복제본에서 기존 테스트와 묶음 칩 컴포넌트 테스트 38개가 통과했다. 설치된 pnpm의 디렉터리 구조에 맞춰 임시 Vitest 설정의 React 별칭 경로만 조정했다. FE 제품 코드는 수정하지 않았다. 배포된 앱/실기기 검증과는 구분한다.
