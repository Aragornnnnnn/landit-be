# LAN-391 시나리오 표현 퀴즈 검수

- 기준: PR #234 `feat/LAN-391`, `e7df116dcfd95b174e3ea57f036a9336507ddf52`.
- 대상: 시나리오 41~70에 연결된 표현 ID 4001~4328, 328개 표현의 추가 예문 1·2번, 총 656문장.
- 이전 LAN-584의 8,000문장 및 첨부 SQL의 3,344문장과 겹치지 않는다. 현재 에이전트가 질문, 번역, 영어 보기, 기존 한국어 허용 배열을 전부 직접 읽었다.
- 미병합 PR의 V136 INSERT를 교정했다. 운영 DB에는 적용하지 않았다. 대표 문장, 예문 3·4, 표현 ID, 시나리오 연결, 이미지 및 발음 자산은 유지한다.

총 636문장에 변경이 있으며 항목별 수치는 중복된다. 한국어 허용 배열은 모두 기본 정답이 첫 배열이며, 복수 정답 334문장과 기본 정답만 있는 322문장으로 구성된다. 임의의 모든 한국어 어순을 허용하지 않는다.

| 표현.예문 | 문제 | 교정 |
| --- | --- | --- |
| 4061.1 | 주말 하나를 고르는데 `help both times`는 두 번 모두 도움이 필요하다는 의미다. | `help either way`로 바꾸고 영어 칩을 동기화했다. |
| 4120.2 | `sign for the box`를 상자 표면에 서명하는 것으로 번역했다. | `택배 기사님이 상자 수령 서명을 해 달라고 하셨어.`로 교정했다. |
| 4249.1 | 이미 City 팬이라고 밝힌 질문에 어느 팀을 응원하느냐고 다시 묻는다. | 질문을 `I've followed football my whole life.`로 바꾸고 질문 번역을 맞췄다. |

기존 한국어 배열 4041.1과 4049.1은 시간 표현의 수식 범위가 바뀌는 어순을 교체했다. 4141.2는 문장 끝에 관형사 `이`가 남는 배열을 제거했다. 영어에서는 `spat/spit`, `should/shall`, `build muscle/muscles`, 한국어 ‘동생’에 대응하는 `sister/brother`, 구동사 분리, 부사구 이동, 독립 문장 순서 교환을 검토했다.

## 검증 및 근거

- [문장별 검수표](quiz-review.csv): 656문장의 출처 ID, 예문 번호, 변경 필드, 교정 칩과 허용 답안.
- [대체 정답 회귀 사례](quiz-regressions.json): 60개 대체 문장이 변경 전 보기로 조립되고 변경 후에는 조립되지 않는지 검사한다. 4061.1은 잘못된 기존 원문이 제거되는 회귀 사례다.
- `python3 -B scripts/verify_scenario_quiz_data.py`: 328개와 656문장 범위, 정답 칩 수량, 영어·한국어 오답 각 3개, 영어 원문 재구성, 강조 구간, 한국어 배열, 예문 3·4 및 메타데이터 보존, 60개 회귀 통과.
- `./gradlew check`: Java 21로 실행. 테스트 1,789개, 실패 0, 오류 0, 기존 비활성 테스트 12개. Spotless와 Checkstyle 통과.
- 격리 PostgreSQL 15: V136 328행 삽입, 한국어 배열, 범위 외 데이터 보존, ID 충돌 보호 검증. V137 발음 자산 984행 적재와 원문 대조 보호 통과. 전체 트랜잭션 롤백 및 임시 서버 종료.
- FE 기준 `492b4ed32805150079ba83c8428e8ebbe95cd5ed`: `word-bank` 및 `QuizStep`, LAN-584 묶음 칩 표시·선택·채점 테스트 33개 통과. FE 코드는 변경하지 않는다.
- 영어 구조 검증과 확인한 대체 답안 회귀는 자동 검사하며, 의미 검수는 직접 수행했다. 가능한 모든 영어 표현의 유일성을 수학적으로 증명한 것은 아니다. CI, 원격 PR 반영, 운영 배포, 실제 기기 레이아웃 검증은 이 로컬 검증에 포함되지 않는다.
